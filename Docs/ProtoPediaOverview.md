# AltitudeZero

> PLATEAUの3D都市モデル内を飛び回り、巨人から都市を守るFPS（一人称視点）アクションゲーム。

## 作品概要

**AltitudeZero**は「PLATEAUの3D都市モデル内を飛び回り、巨人から都市を守るFPS（一人称視点）アクションゲーム」です。現在は新宿区の街並みに巨人を配置し、左右2本のワイヤーを使った立体移動を体験できるプロトタイプを制作しています。

## 体験できること

- 左右のアンカーを建物や地面に打ち込み、ワイヤーを巻き取って移動できます。アンカーを外すと重力が戻り、落下やワイヤーにつながれた状態での移動へ切り替わります。
- 巻き取り中に壁へぶつかった場合は、その接触位置で停止します。ワイヤーは接続中、まっすぐ張った状態で表示されます。
- ミニマップで自分と巨人の位置を確認できます。周辺表示と広域表示の切り替えにも対応しています。

## 制作で工夫したこと

PLATEAUの都市モデルをゲームのフィールドとして使えるよう、地形と建物の形状を計測し、BoxColliderを一括生成するUnity Editorツールを作りました。現在のシーンでは、地形に361個、建物396棟に各1個、合計757個のBoxColliderを配置しています。建物は細部まで当たり判定を分割せず、大まかな箱で近似しています。

移動にはUnity Starter AssetsのFPSコントローラーを使用し、アンカーの巻き取り中もキャラクターと街の衝突を判定します。入力、ワイヤーの表示、アンカーの接続状態、接触位置での停止を組み合わせ、都市を立体的に移動する手触りを試しています。

## 開発状況

現在は**移動とフィールドを中心とした開発中のプロトタイプ**です。巨人はシーンに配置していますが、攻撃、ダメージ、討伐判定などのボス戦は今後実装する予定です。さらに、WebRTCで参加プレイヤーの位置や向きを同期するマルチプレイも構想しています。

**使用技術：** Unity、PLATEAU SDK for Unity、Unity Starter Assets、Input System、Cinemachine、URP、UniVRM
