# AltitudeZeroのストーリー

## 都市を「眺める」から「飛び回る」へ

PLATEAUの3D都市モデルの中を、自分の手で飛び回れたらどうなるだろう。そんな発想から、巨人に襲われる都市を守るFPSアクションゲーム「AltitudeZero」を制作しています。建物の間を縫い、屋上へ駆け上がり、巨人を追う。実在の街並みを舞台にすることで、移動そのものが楽しいゲームを目指しています。

## まずは、街を自由に移動するところから

現在のプロトタイプでは、新宿区の3D都市モデルと巨人をシーンに配置しています。左右それぞれの手から建物や地面へアンカーを打ち込み、ワイヤーを巻き取って飛ぶことができます。両方のアンカーを外すと重力で落下し、打ち込んだままならワイヤーにつながれた状態で移動します。ミニマップには自分と巨人の位置が表示されます。

都市モデルをゲームのフィールドとして使うには、地面や建物に当たり判定が必要でした。そこでMeshを計測し、地形と建物にBoxColliderをまとめて配置できるUnity Editorツールを作りました。アンカーの巻き取り中も壁との衝突を判定し、途中でぶつかった場所で止まるようにしています。

## これから作りたい光景

今は移動とフィールドを中心に作っている段階です。今後は、巨人の行動、攻撃、ダメージ、討伐までを実装し、「都市を守る」ゲームとして完成させたいと考えています。

さらにマルチプレイにも挑戦する予定です。ほかのプレイヤーが同じ都市に参加し、WebRTCで位置や向きなどを同期することで、みんなが建物の間を飛び回り、巨人に立ち向かう光景を実現したいです。
